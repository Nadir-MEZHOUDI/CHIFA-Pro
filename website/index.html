Mode d'emploi

Comment ça marche ?

  1. Téléchargez l'installateurCliquez sur Télécharger SmartCHIFA et enregistrez le fichier sur le PC de l'officine.
  2. Lancez l'installationDouble-cliquez sur le fichier. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires puis Exécuter quand même. Un raccourci est créé sur le Bureau.
  3. Activez votre licenceAu premier lancement, cliquez sur Demander une licence et remplissez le formulaire. Vous avez déjà un numéro de série ? Saisissez-le puis cliquez sur Activer.
  4. Connectez la base CHIFA_OFFICINEGlissez l'icône CHIFA_OFFICINE du Bureau dans la fenêtre (ou Parcourir…), puis Tester et Enregistrer. Vos factures apparaissent aussitôt.
  5. Pilotez votre officineUtilisez le menu à gauche : Accueil, Factures, Bordereaux, Psychotropes, Statistiques… Choisissez la période en haut de chaque écran.
  6. Liez votre téléphone (facultatif)Ouvrez Application mobile dans le menu, scannez le QR code avec votre téléphone et saisissez le code affiché.

Sécurité et confidentialité

Vos données restent chez vous. Votre téléphone se lie en quelques secondes.

La sécurité sans la complexité : aucun serveur ne stocke vos données, aucun port à ouvrir, aucun réglage réseau. Il suffit de scanner le code affiché à l'écran.

Vos données ne quittent pas la pharmacie

La base CHIFA et l'historique de vos patients restent sur le PC de l'officine. Rien n'est copié ni hébergé sur un serveur externe : le téléphone affiche uniquement ce que vous consultez, au moment où vous le consultez.

  • Aucune copie en ligne
  • Secret médical respecté

Aucun port à ouvrir

Pas de réglage du routeur, pas d'adresse IP fixe, pas de technicien réseau. SmartCHIFA se connecte en sortie, comme un navigateur, par un canal chiffré : votre PC reste invisible depuis Internet.

Personne ne voit vos informations

Personne ne peut accéder à vos données sans votre accord : seuls les téléphones que vous avez liés vous-même y ont accès, et vous pouvez en retirer un à tout moment depuis SmartCHIFA.

Un QR code, et c'est tout

Ouvrez Application mobile dans SmartCHIFA et scannez avec votre téléphone le QR code affiché à l'écran. Le code ne sert qu'une seule fois et expire au bout de quelques minutes.

FAQ

Questions fréquentes

Dois-je ressaisir mes factures ?

Non. SmartCHIFA lit directement la base de votre logiciel CHIFA officine. Vos factures, assurés et bordereaux apparaissent dès l'installation.

Mes données partent-elles sur internet ?

Non. Tout reste sur le PC de votre officine. L'application mobile interroge votre officine à la demande via une connexion chiffrée ; rien n'est conservé sur nos serveurs.

Que se passe-t-il si internet est coupé ?

L'application sur PC continue de fonctionner normalement. Seul l'accès depuis le téléphone attend le retour de la connexion.

Comment fonctionne la licence ?

Chaque licence est liée à un poste. Après l'essai, vous recevez un numéro de série à saisir dans l'application, sans réinstallation.

Comment se font les mises à jour ?

Automatiquement, en arrière-plan. Seules les modifications sont téléchargées, la mise à jour prend quelques secondes.
